# Kiosk Browser Android — Полная история разработки, архитектура и документация проекта

> **Документ создан для разработчиков и AI-ассистентов.** Содержит полную историю всех изменений, архитектурные решения, описание каждого компонента, решения возникших проблем и инструкции по дальнейшей поддержке и сборке проекта.

---

## 1. Обзор проекта и назначение

- **Название:** Kiosk Browser Android («Kiosk Gusar»)
- **Идентификатор пакета (Application ID):** `com.kiosk.browser`
- **Репозиторий GitHub:** [druzhba-tech/Kiosk1](https://github.com/druzhba-tech/Kiosk1)
- **Основная ветка:** `main`
- **Основное применение:** Круглосуточная (24/7) работа на планшетах в ресторанах, кухнях (экраны поваров KDS — Kitchen Display System, например GUSAR-POS), кассовых терминалах (POS), экранах электронной очереди и интерактивных киосках самообслуживания.
- **Технологический стек:**
  - Язык: Kotlin 1.9.23
  - UI: Jetpack Compose + Material3 (стилизован в темной киберпанк-эстетике: CyberCard, NeonCyan, NeonGreen, NeonOrange, NeonRed)
  - WebView: Chromium WebKit с двусторонним JavaScriptBridge (`window.kiosk` и `window.fully`)
  - Администрирование: Android Enterprise Device Owner (DPM — DevicePolicyManager)
  - Архитектура: Модульная (Admin, Core, Data, UI, Service)
  - Сборка и CI/CD: Gradle Kotlin DSL + GitHub Actions (`.github/workflows/build-apk.yml`)

## 2. Хронология версий и история всех выполненных доработок

### Версии v1.0.1 — v1.0.9: Базовый функционал киоска
- Полноэкранный Kiosk-режим (Immersive Mode: скрытие системного статус-бара и навигационных кнопок Android).
- Защита настроек мастер-PIN кодом (по умолчанию `1234`).
- Плавающая информационная панель (Cyber HUD) с возможностью перемещения (верх-право, верх-лево) и настройки отступа от края экрана в сантиметрах.
- Белый и черный списки URL-адресов.
- Интеграция с Home Assistant и MQTT-брокером (отправка статуса батареи, заряда, температуры, прием команд экрана).
- Встроенный локальный HTTP REST API на порту 8080 для удаленного управления.
- NFC ридер (передача прочитанных меток в JavaScript: `window.onNfcScanned`).
- Заставка (Скринсейвер) с защитой от выгорания OLED-экранов.

### Версия v1.0.10: Первоначальная настройка и пароли
- Создан пошаговый мастер первоначальной настройки (**FirstRunSetupDialog**): позволяет администратору при первом включении ввести стартовый URL, выбрать режим (Веб-сайт или Android-приложение), задать PIN-код.
- Запоминание паролей: встроенный **PasswordManager** с шифрованием паролей пользователей в EncryptedSharedPreferences и автоматической инъекцией логинов и паролей на веб-страницах.
- Секретный жест открытия настроек (**SecretGestureDetector**): пятикратное быстрое нажатие в правый верхний угол экрана вызывает ввод PIN-кода даже при скрытой панели.

### Версия v1.0.11: Режим Device Owner и лаунчер по умолчанию
- Назначение постоянным системным лаунчером (`setDefaultLauncher(true)`).
- Аппаратная изоляция LockTask (`startLockTask()`), блокировка Safe Mode и монтирования флешек/USB.
- Устранение проблемы случайного запуска Home Assistant при первом старте.

### Версия v1.0.12: Микшер громкости и единый Keystore
- Добавлен **микшер громкости** в плавающую панель (HUD) и отдельная карточка управления в меню «Настройки»:
  - Слайдер громкости мультимедиа и заказов (`STREAM_MUSIC`) с отображением процентов (0..100%).
  - Слайдер громкости уведомлений и системных звонков (`STREAM_NOTIFICATION`).
  - Динамическая смена иконки динамика (Mute, VolumeDown, VolumeUp) и поддержка системного слушателя `VOLUME_CHANGED_ACTION`.
- Настройка постоянного неизменного ключа цифровой подписи: `kiosk.keystore` (пароль `kioskpassword`, алиас `kiosk`), чтобы при последующих обновлениях никогда не возникал конфликт подписей Android.

### Версия v1.0.13: Устранение ошибки «Пакет недействителен (поврежден)»
- **Причина ошибки**: 
  1. При фоновом скачивании поток писал напрямую в файл `.apk` в кэше. При обрыве связи или редиректах на GitHub Releases файл оставался неполным (битый ZIP).
  2. В конфигурации Gradle отсутствовала классическая подпись V1 JAR Signature (`CERT.RSA`, `CERT.SF`, `MANIFEST.MF`), из-за чего ряд прошивок планшетов выдавали ошибку `INSTALL_PARSE_FAILED_NO_CERTIFICATES` или `INSTALL_PARSE_FAILED_NOT_APK`.
- **Решение**:
  - В `build.gradle.kts` включены `enableV1Signing = true` и `enableV2Signing = true`.
  - Внедрена атомарная загрузка через буферный файл `.apk.tmp`.
  - Добавлена функция проверки `isValidApk(file)`: проверяет корректность структуры ZIP-архива, наличие `AndroidManifest.xml` и `classes.dex`, а также размер. Битые файлы автоматически удаляются и скачиваются заново.

### Версия v1.0.14: Сеть, мобильный интернет, блокировка звонков/SMS и фикс скролла
- **Исправление статуса Wi-Fi**:
  - На современных Android 10+ устаревший вызов `wifiManager.connectionInfo` возвращал `networkId = -1` без включенной геолокации, из-за чего диалог ошибочно писал «Не подключено».
  - Переведено на `ConnectivityManager.getNetworkCapabilities()` и `LinkProperties` (IPv4). Теперь статус подключения, реальный IP-адрес и SSID определяются безошибочно.
- **Поддержка мобильных сетей (SIM-карта / 4G / LTE)**:
  - В диалог сети добавлена карточка сотовой связи: отображается оператор (Tcell, Мегафон и др.), статус мобильного интернета, реальный IP.
  - Кнопка быстрого доступа к настройкам передачи данных и шторке интернета Android без выхода из киоска.
- **Блокировка входящих/исходящих звонков и SMS (для SIM-карт)**:
  - Device Owner ограничения: `UserManager.DISALLOW_OUTGOING_CALLS` и `UserManager.DISALLOW_SMS`.
  - Ресивер `CallBlockReceiver`: мгновенно отклоняет (`telecomManager.endCall()`) входящие звонки на SIM-карту и глушит рингтон, исключая перекрытие экрана поваров KDS.
  - Ресивер `SmsBlockReceiver`: перехватывает входящие SMS с приоритетом 999 (`abortBroadcast()`).
  - Блокировка ссылок `tel:` и `sms:` из браузера.
- **Запрет раздачи интернета сотрудниками**:
  - Добавлена политика `UserManager.DISALLOW_CONFIG_TETHERING` (запрет Wi-Fi Hotspot).
- **Исправление свайпа обновления (Pull-to-refresh)**:
  - Ранее свайп сверху вниз в середине длинной страницы вызывал перезагрузку сайта вместо прокрутки наверх.
  - Решение: динамическое отключение `swipeRefresh.isEnabled = false` при `scrollY > 0`. Свайп в середине страницы плавно прокручивает страницу вверх к началу. Обновление срабатывает строго только тогда, когда пользователь уже на самом верху (`scrollY == 0`).
  - Добавлен DOM-слушатель через `JavaScriptBridge.notifyScrollAtTop()` для Single Page Applications (React/Vue).
- **Защита от случайного зума на кухне**:
  - Отключен встроенный зум WebView (`supportZoom = false`, `builtInZoomControls = false`) и внедрен мета-тег `user-scalable=no` с фильтрацией быстрого двойного тапа (double-tap zoom).
- **Защита от случайного выключения звука заказов**:
  - Фоновый сторож автоматически восстанавливает громкость `STREAM_MUSIC` не ниже 60%, если кто-то зажал качельку громкости планшета.
- **Ежедневная тихая ночная перезагрузка страницы (в 04:00 утра)**:
  - Фоновый процесс каждую ночь тихо перезагружает сайт, освобождая память WebKit от накопленного кэша при работе 24/7.

### Версия v1.0.15: Полноценный выбор лаунчера по умолчанию (Default Launcher Picker)
- **Выбор лаунчера из установленных в системе**:
  - Создан специализированный диалог `LauncherPickerDialog` в киберпанк-стиле.
  - Автоматически находит все установленные рабочие столы (Kiosk Browser, системный рабочий стол Launcher3 / One UI / MIUI, сторонние лаунчеры) с системными иконками, именами пакетов и радио-кнопками.
  - Позволяет администратору в один клик переключить лаунчер по умолчанию на системный рабочий стол или любой другой лаунчер.
- **Управление через DevicePolicyManager**:
  - Метод `DeviceOwnerManager.setPreferredLauncher(packageName, activityName)` безопасно очищает предыдущие привязки через `clearPackagePersistentPreferredActivities` и назначает выбранный лаунчер через `addPersistentPreferredActivity`.
  - Метод `clearDefaultLauncher()` сбрасывает постоянное назначение (система запрашивает выбор при нажатии кнопки Home).
  - Метод `openHomeSettings()` обеспечивает безопасный переход в системный выбор приложений по умолчанию Android (`RoleManager.ROLE_HOME` или `ACTION_HOME_SETTINGS`).
- **Интерактивная карточка в меню «Настройки» (`SettingsScreen`)**:
  - Динамически определяет текущий статус: активен ли Kiosk, сторонний рабочий стол или выбор не назначен.
  - Кнопка «Выбрать лаунчер», быстрая кнопка «Вернуть Kiosk» и переход в настройки Android.
- **Защита от перезаписи пользовательского выбора в `MainActivity`**:
  - Параметр `preferredLauncherPackage` сохраняется в `KioskConfig`. При сворачивании или перезапуске (`onResume` / `applyConfigUpdates`) приложение больше не перебивает принудительно выбор администратора, если был выбран сторонний рабочий стол.

### Версия v1.0.16: Сторож от падений (Crash Watchdog) и оффлайн-экран потери сети
- **Сторож от падений (Crash Watchdog / Auto-Restart)**:
  - В `KioskApp` внедрен глобальный обработчик `Thread.setDefaultUncaughtExceptionHandler`.
  - При возникновении критического сбоя в любом потоке Kiosk не показывает системное окно Android «Приложение остановлено».
  - Стек-трейс ошибки атомарно сохраняется в файл `crash_log.txt` во внутреннее хранилище для диагностики.
  - Через `AlarmManager` планируется немедленный перезапуск `MainActivity` с флагами `FLAG_ACTIVITY_NEW_TASK or FLAG_ACTIVITY_CLEAR_TASK`. Процесс мгновенно оживает, гарантируя бесперебойный прием заказов 24/7.
- **Стилизованный кибер-оверлей при потере связи с сервером (Offline Error Screen)**:
  - `KioskWebViewClient` перехватывает ошибки загрузки основного фрейма (`onReceivedError`, `ERROR_HOST_LOOKUP`, `ERROR_CONNECT`, `ERROR_TIMEOUT` и др.).
  - Вместо стандартного серого динозаврика Chromium отображается стильный киберпанк-оверлей:
    - Предупреждение «СВЯЗЬ С СЕРВЕРОМ ПОТЕРЯНА» с описанием причины.
    - Автоматический таймер обратного отсчета (5 секунд) с круговым индикатором и автоперезагрузкой сайта.
    - Кнопка немедленного ручного повтора «ПОВТОРИТЬ».
    - Кнопка быстрого доступа к настройкам сети («Сеть / Wi-Fi»).
  - При восстановлении связи или успешной загрузке страницы оверлей мгновенно автоматически скрывается.

### Версия v1.0.17: Исправление видимости лаунчеров (Package Visibility) и разблокировка LockTask
- **Исправление видимости установленных рабочих столов в Android 11+**:
  - Начиная с Android 11 (API 30+) система скрывает другие приложения от `queryIntentActivities`, если они явно не запрошены.
  - В `AndroidManifest.xml` добавлены разрешение `QUERY_ALL_PACKAGES` и блок `<queries>` для категорий `CATEGORY_HOME` и `CATEGORY_LAUNCHER`.
  - Теперь `LauncherPickerDialog` безошибочно видит и выводит все системные и сторонние рабочие столы (One UI Home, MIUI, Pixel Launcher, Launcher3, Nova и др.).
- **Исправление системного диалога назначения лаунчера**:
  - В `DeviceOwnerManager.openHomeSettings()` исключен ошибочный вызов `roleManager.createRequestRoleIntent`, который запрашивал роль для Kiosk вместо стороннего лаунчера. Теперь напрямую открываются настройки домашних экранов Android (`Settings.ACTION_HOME_SETTINGS`).
  - При выборе стороннего лаунчера автоматически вызывается `stopLockTask()`, предотвращая блокировку экрана в режиме киоска.

## 4. Пайплайн сборки и выкатки обновлений (CI/CD)

В окружении Windows, где прямой CLI `git` может отсутствовать в PATH, выкатка изменений на GitHub настроена через официальный REST API GitHub с помощью скриптов PowerShell в папке `scratch/`:

1. **`scratch/push_to_github.ps1`**:
   - Читает измененные исходные файлы с диска.
   - Создает Git Blobs через API GitHub (`POST /repos/:repo/git/blobs`).
   - Создает Git Tree и новый коммит от имени репозитория.
   - Обновляет ссылку ветки `refs/heads/main`.
2. **GitHub Actions (`.github/workflows/build-apk.yml`)**:
   - Срабатывает автоматически при пуше в `main`.
   - Запускает Ubuntu runner с JDK 17 и Android SDK 34.
   - Выполняет `./gradlew assembleRelease`.
   - Подписывает APK постоянным ключом `app/kiosk.keystore` с сигнатурами V1 + V2.
   - Создает официальный релиз с тегом `vX.Y.Z` и прикрепляет файл `kiosk-browser-vX.Y.Z.apk`.
3. **`scratch/wait_for_run.ps1`**:
   - Опрашивает статус последней сборки GitHub Actions до статуса `completed` (`success`).
4. **`scratch/check_releases.ps1`**:
   - Проверяет список опубликованных релизов и генерирует прямую ссылку на скачивание APK.

## 5. Инструкция для будущих сессий Antigravity / AI-ассистентов

При возобновлении работы над проектом:
1. **Текущая версия проекта**: `v1.0.18` (versionCode `19`).
2. **Всегда сохранять совместимость подписи**:
   - Никогда не удалять и не перезаписывать файл `app/kiosk.keystore`.
   - В `app/build.gradle.kts` всегда должны оставаться `enableV1Signing = true` и `enableV2Signing = true`.
3. **Новые сборки**:
   - При внесении изменений увеличивать `versionCode` на +1 и `versionName` (например, `16` и `"1.0.15"`).
   - Запускать отправку через `push_to_github.ps1`.
4. **Особые системные требования**:
   - Для работы блокировок вызовов, статус-бара и навигации киоск должен быть назначен Device Owner командой:
     ```bash
     adb shell dpm set-device-owner com.kiosk.browser/.admin.KioskDeviceAdminReceiver
     ```
